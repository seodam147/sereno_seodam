I created this tool with a simple idea : while working in the server room, I wondered
if I could view all the monthly server check items with just a single click instead of
manually running commands and navigating through menus every time.
While it might be a small tool, I hope it brings a bit of convenience to your dailyroutine.
The source code is provided so you can modify and adapt it to your needs.
